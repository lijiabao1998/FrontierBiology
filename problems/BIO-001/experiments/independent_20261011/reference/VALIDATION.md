# 生物線驗證契約

## 子任務先凍結
記物種／細胞／組織／測量技術、樣本與資料來源、版本與license、分析單位、對照、排除準則、模型、主指標及其信賴區間、成功閾值。廣泛問題先拆成可驗證子任務，不能在結果出現後換成功定義。

## 核心守衛
- 資料解析及缺失值檢查；donor／研究／時間／同源群的切分不洩漏。
- 簡單零效應／均值／線性或加成基線先跑；新模型同一預算同一測試集比較。
- 事前訂多重比較與不確定性處理；不從100個失敗seed中只報最好的。
- 合成已知真值與真實資料分開列，不把合成成功當自然界機制。
- 評分實作獨立核對；做標籤打乱／資料交叉污染等負控制，確認守衛能報錯。
- 發現型資料與確認型資料分開；無獨立資料時明列限制，不寫已獨立重現。

廣泛機制的完成需要與題卡同範圍、可支持的證據，必要時仍需實驗。計算型結果可以形成有價值假說，但不能跨過因果或實驗邊界。任何高風險研究、臨床或濕實驗不得由agent自行開啟。
